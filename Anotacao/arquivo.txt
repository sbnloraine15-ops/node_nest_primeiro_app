    Main inicia o projeto
    Quando fazemos uma requisição, primeiro arquivo a ser chamado é o controller
    No controler ele indentifica e chama o serviço
    serviço é responsavel por fazer a lógica pesada, cominicação com o banco de dado, faz alguma logíca e retorna para o usuario.
    Module arquivo onde de fato eu terei a cinfiguração do item 

    *Basicamente o main inicia, o controler ve a requisição a chamada que se quer entrar, entra na rota no método  o  serviço faz a logica e devolve para o usuario.

PRISMA 
    Comandos: 
        npm install prisma@7.10.0 @types/node @types/better-sqlite3 --save-dev
        npm install @prisma/client@7.10.0 @prisma/adapter-better-sqlite3 dotenv

            prisma- A CLI do Prisma para executar comandos como prisma init, prisma db pull, eprisma generate
            @prisma/client- A biblioteca Prisma Client para consultar seu banco de dados
            @prisma/adapter-better-sqlite3- O adaptador de driver SQLite que conecta o Prisma Client ao seu banco de dados
            @types/better-sqlite3- Definições de tipo TypeScript para better-sqlite3
            dotenv- Carrega variáveis ​​de ambiente do seu .envarquivo

        npx prisma init 
            Cria um prisma/diretório com um schema.prismaarquivo contendo a configuração de conexão do seu banco de dados.
            Cria um .envarquivo no diretório raiz para variáveis ​​de ambiente.
            Cria um prisma.config.tsarquivo para configuração do Prisma.
